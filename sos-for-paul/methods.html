Real SOS Gaussianity experiment

Latest results: the page now includes compiled runs through n = 2048, described in scaling-limit-guess.md, with fitted marginal curves and joint-law comparisons. New native intervals use 1,000 bootstrap resamples stratified by chain, with blocks of 512 recordings. The earlier continuation-results.md uses 800 resamples and is archived as experiments/continuation-256.*. The original JavaScript settings and first-run results below remain useful for the numerical specification; experiments/first-run.* preserves that first run.

The experiment uses real heights, q = 1, α = 2.25, β = 1, on the 2n + 1 sites −n,…,n with zero heights at every exterior site. It preserves the ordered-pair energy convention and full exterior tails documented in paper-notes.md. The previous index.html remains an integer-valued comparison; gaussianity.html is the real-valued experiment.

Observable and normalization

The test function is the smooth bump

f(t) = exp(1 − 1/(1 − (t/0.8)^2)) for |t| < 0.8,
       0 otherwise.

We also sample g(t) = 3(t/0.8)f(t), and display f, g, f+g, f−g and f+2g projections. Each sampled configuration supplies both sums, preserving their joint law.

The raw pairing is X_n = Σ f(x/n)φ(x). The user’s observable is n^(−1/2)X_n at α = 2.25. A candidate amplitude exponent H = 1/4 instead gives n^(−5/4)X_n: n^(−1) is the Riemann-sum factor and n^(−1/4) rescales the field. Both normalizations are evaluated. Their standardized histograms are identical, but their unstandardized variances have different size dependence.

Sampling

Each continuous Metropolis sweep contains 2n+1 random local proposals, four interval translations, and one smooth collective translation. Proposals have continuous, symmetric, state-independent amplitudes. Smooth directions include the constant vector and even/odd bumps; their scales are set from each direction’s energy at the zero profile. Acceptance is min(1, exp(−βΔH)). No integer rounding, height cutoff, or distance cutoff is used.

Three separate seeds start from a flat, positive bump, and negative bump profile. The standard run uses 8,000 warmup sweeps followed by 4,000 recorded samples per chain at spacing five sweeps. Sampling β = 1 loses no shape information for this real homogeneous model: multiplying heights by β^(−1/q) changes inverse temperature from 1 to β.

The q = 2 control uses independent exact Gaussian vectors generated by a Cholesky solve of the precision matrix 4βL. It bypasses MCMC and calibrates the normality plots and moment estimates. It does not replace the q = 1 sampler.

Diagnostics and limits

Excess kurtosis is the empirical centred fourth moment divided by the square of the empirical variance, minus 3. The displayed interval resamples contiguous blocks independently across the pooled collection of within-chain blocks; blocks never cross chain boundaries. Their length is at least 32 saved samples and increases with the estimated autocorrelation time of X², capped so that each chain contributes at least eight blocks. The interval uses 240 block-bootstrap resamples. It is approximate and can miss slow correlations.

Split R-hat is the traditional variance-based diagnostic, computed on split chains for X, X² and the odd projection. It is not rank-normalized. ESS uses a monotone initial-positive sequence of autocorrelation pairs, limited to at most 1,000 lags. These diagnostics may miss metastability or correlations beyond the recorded window. They cannot certify convergence.

The mixed fourth cumulant is centred empirically and normalized by Var(X)Var(Y). It should vanish for a jointly Gaussian pair. Testing several projections and one mixed cumulant probes joint Gaussianity but cannot establish it. Q-Q plots use the central 99% of empirical quantiles and are visual diagnostics.

The increment plot uses centre-anchored increments at separations up to n/2 and an amplitude-fitted candidate power law. Boundary effects persist on the rescaled fixed domain. A fractional Brownian motion claim would additionally require appropriate covariance, self-similarity and tightness, beyond these finite-size tests.

Reproduce

node test-real-model.cjs
node run-real-experiment.cjs
open gaussianity.html

To change the command-line budget, set SOS_SAMPLES, SOS_BURN, SOS_THIN or SOS_SIZES. For example:

SOS_SAMPLES=16000 SOS_BURN=30000 SOS_THIN=10 SOS_SIZES=16,32,64,128 node run-real-experiment.cjs

The command-line run overwrites the saved real-SOS results. Set SOS_Q=2 for a separately named Gaussian benchmark. node check-real-browser.cjs checks offline page loading, controls, mobile layout and the exact-Gaussian browser run.
