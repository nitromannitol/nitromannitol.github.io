Continued real-SOS experiment

This is the earlier continuation through n = 256, archived in experiments/continuation-256.*. The current HTML and canonical real-sos-results.* files now include new compiled runs through n = 2048; see scaling-limit-guess.md.

Real heights; q = 1, α = 2.25, β = 1; smooth bump supported in [−0.8,0.8]. Each size has three fresh seeds, 20,000 warmup sweeps and 16,000 recorded samples per chain, with five sweeps between samples. This is 300,000 total sweeps and 48,000 saved configurations per size. The first run is preserved in experiments/first-run.*.

Intervals use 800 bootstrap resamples of blocks of 512 saved configurations (2,560 sweeps), formed within individual chains. Sensitivity checks at block lengths 32 and 128, per-chain moments, early/late halves and autocorrelation estimates for the kurtosis influence function are in experiments/continuation-audit.json. These checks reduce concern about short-block error estimates; they do not guarantee mixing.

For the real q = 1 homogeneous energy in dimension m = 2n + 1, βH has a Gamma(m,1) distribution, hence E[βH]/m = Var(βH)/m = 1. The new run records both quantities as sampler checks. This identity follows by scaling the finite-dimensional partition integral, without a Gaussian assumption.

The inferred pairing exponent from the largest three completed sizes is H ≈ 0.235; the centre-height second moments give H ≈ 0.235. These are finite-size fits. They do not identify an asymptotic exponent or establish fBm convergence.

The finite-size kurtosis trend is the main question: a positive value at finite n does not exclude convergence to a Gaussian. Larger boxes, control of sampling error and covariance convergence remain necessary.

Reproduce the main continuation with:

SOS_SAMPLES=16000 SOS_BURN=20000 SOS_THIN=5 SOS_SEED=425715 SOS_SIZES=8,16,32,64,128,256 SOS_OUTPUT=experiments/continuation node run-real-experiment.cjs

All raw samples and settings are available in real-sos-results.json and real-sos-results.csv; gaussianity.html loads the corresponding JavaScript data file offline.

Independent Gaussian control

The Gaussian control has much smaller excess kurtosis than q = 1. Its n = 256 interval narrowly excludes zero despite exact Gaussian sampling, illustrating the false positives possible with nominal 95% intervals. The IID reference standard error for excess kurtosis is approximately sqrt(24/48000) = 0.022. The continuation uses longer bootstrap blocks for q = 1 and reports sensitivity checks rather than treating an interval as a proof.
