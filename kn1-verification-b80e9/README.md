# Kozma–Nitzan conjectures: Lean certificates on top of the θ(p_c) = 0 development

* `lean/` — fourteen Lean modules: Conjectures 1–4 (Conjecture 4 also in the paper's cluster-property vocabulary), Question 7,
  the probabilistic half of Question 5, and lemmas toward Conjecture 6; `README.md`, `VERIFICATION.log`.
* `document/` — the document proposing proofs of all nine numbered items of the paper (PDF and TeX).
* `conjecture-1/` — the earlier certificate for Conjecture 1 alone, with `SOURCES.sha256` pinning the development's sources
  (tree hash `b80e9252…`); not needed to build `lean/`.
* `index.html` (this page), `LICENSE`, `NOTICE`.
